
## ABSTRACT

本文聚焦查询优化中最核心的 join ordering（连接顺序）问题。已知有两种高效算法能在避免笛卡尔积的前提下求最优连接顺序：基于动态规划的 DPccp，以及基于 memoization 的 Top-Down Partition Search。但二者都存在两个严重局限：它们只能处理 (1) 简单的二元连接谓词，以及 (2) 内连接。而真实查询往往包含涉及两个以上关系的复杂连接谓词，以及外连接（outer join）等非内连接。

作者以效率最高的已知连接顺序算法 DPccp 为起点，提出新算法 **DPhyp**：通过把查询图建模为（超图的一种变体）hypergraph，并分析其连通子图，从而高效处理复杂连接谓词；在此基础上，进一步扩展该能力，以处理迄今为止覆盖范围最广的非内连接类别。实验结果表明，把非内连接重写为复杂谓词的这一做法，相比已知的、处理复杂连接谓词与非内连接的算法，可将优化时间提升数个数量级。这再次让动态规划对当前的 memoization 技术取得了明显优势。
